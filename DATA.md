# Training data and licences

Kadmos-1 was trained on the public datasets below. Licences are copied from each dataset's Hugging Face card where one is declared. Where no licence is declared on the card, this file says so rather than guessing; check the original source before relying on the data for anything beyond research.

| Dataset | Used for | Licence on the dataset card |
|---|---|---|
| [roneneldan/TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories) | Stories | CDLA-Sharing-1.0 |
| [codeparrot/codeparrot-clean](https://huggingface.co/datasets/codeparrot/codeparrot-clean) | Python files | None declared on the card. The files are public GitHub code under their original repository licences |
| [roskoN/dailydialog](https://huggingface.co/datasets/roskoN/dailydialog) | Conversation | None declared on the card. The original DailyDialog release is CC BY-NC-SA 4.0 (non-commercial) |
| [facebook/empathetic_dialogues](https://huggingface.co/datasets/facebook/empathetic_dialogues) | Conversation | CC BY-NC 4.0 (non-commercial) |
| [allenai/soda](https://huggingface.co/datasets/allenai/soda) | Conversation (generated by a language model) | CC BY 4.0 |
| [OpenAssistant/oasst1](https://huggingface.co/datasets/OpenAssistant/oasst1) | Conversation | Apache-2.0 |
| [Anthropic/hh-rlhf](https://huggingface.co/datasets/Anthropic/hh-rlhf) (helpful-base, helpful-online, helpful-rejection-sampled) | Conversation | MIT |
| [HuggingFaceTB/everyday-conversations-llama3.1-2k](https://huggingface.co/datasets/HuggingFaceTB/everyday-conversations-llama3.1-2k) | Conversation (generated by a language model) | Apache-2.0 |
| [iamtarun/python_code_instructions_18k_alpaca](https://huggingface.co/datasets/iamtarun/python_code_instructions_18k_alpaca) | Code Q&A | None declared on the card |
| [sahil2801/CodeAlpaca-20k](https://huggingface.co/datasets/sahil2801/CodeAlpaca-20k) | Code Q&A (generated by a language model) | CC BY 4.0 |
| [flytech/python-codes-25k](https://huggingface.co/datasets/flytech/python-codes-25k) | Code Q&A | None declared on the card |

## Implications for the weights

Because some of the data is non-commercial (EmpatheticDialogues, and DailyDialog under its original terms) and the weights are trained on it, the released weights should be treated as research and personal-use only. The code in this repository is MIT licensed and does not include any of the data.
